# AI Engineer in 90 Days

A month-by-month learning scaffold for building practical AI engineering skills.

## Structure

- `month-01/` — Foundations and first hands-on projects
- `month-02/` — Model integration, retrieval, and application development
- `month-03/` — Evaluation, deployment, and a capstone project

Each month is organized into weeks, and each week can contain daily tasks and notes.

## Getting started

Start with [Month 1, Week 1](month-01/week-01/README.md). The Day 1 starter script
uses only the Python standard library:

```powershell
python month-01/week-01/day-01/day01_task_assistant.py
```

Add your notes, exercises, and project work to the corresponding week and day
folders as you progress.
